# おトク発見ナビ 導入管理画面

購入者向けの導入・設定・保守を行う独立した管理画面です。既存の公開サイトおよび運営者用管理画面とは分離して開発します。

## 現在の実装
- 多言語共通基盤の初期版
- 対応言語：日本語、英語、中国語（簡体字・繁体字）、韓国語
- 初回アクセス時はブラウザ言語を判定
- 手動で選択した言語は localStorage に保存し、次回アクセスでも優先
- 翻訳ファイルが読み込めない場合は日本語へフォールバック
- 言語設定はこの導入管理画面内で独立して管理

## ファイル構成
- `index.html`
- `css/language.css`
- `js/language.js`
- `languages/ja.json`, `en.json`, `zh-CN.json`, `zh-TW.json`, `ko.json`

## 確認
GitHub Pages またはローカルHTTPサーバーで開いてください。翻訳JSONを fetch するため、`file://` 直開きではなくHTTP経由で確認してください。
